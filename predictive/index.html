The three mechanical operations

1. WRITE

The pair of observations determines a temporal residue: Δ = x(t+1) − x(t). Its address is the coarse signal plus optional recent motion. The transition is stored only after it has happened.

2. QUERY

A new address activates the six closest stored transitions. Their deltas are blended using similarity and recency. The result is added to the current signal to predict one tick ahead.

3. CORRECT

The next observation exposes the error. Close matching past transitions receive a small correction, and the newly observed transition is stored. Old entries fade in relevance and leave the finite memory.

address(t)  = [low_frequency(x(t)), low_frequency(x(t) - x(t-1))]
memory      = {(address(j), x(j+1)-x(j)) : j < t}
reactivated = Σ similarity(address(t), address(j)) × delta(j)
predict     = x(t) + reactivated
surprise    = x(t+1) - predict
write       = (address(t), x(t+1)-x(t))          // only after observing t+1

Limits: This is an online nearest-neighbour transition memory, related to established associative memories and local dynamical models—not a newly discovered neuron or a trained world model. It performs best on recurring states and motion patterns. Webcam footage, unfamiliar actions, lighting changes and non-periodic motion may defeat it. Only measured error against hold-last establishes whether it helps on your signal. Video frames and memory stay in your browser; export contains error statistics, not camera images.
