A lossless decomposition is guaranteed by telescoping. Useful segmentation is not. The crucial missing step is how to turn this residue energy into good graph edges.

What the actual graph experiment found

The Python benchmark used the original five Sihti scenes, 72×96 resolution, normalized-cut spectral modes, and a signed / unsigned / shuffled control. The initially proposed weight β = 1 failed. Higher weights were explored after seeing this failure.

The first test failed.

The raw self graph grouped stripes better than the unsigned-feedback graph. Simply connecting the sieve's exhaust back to the graph was insufficient.

The exploratory β=8 result averages 0.970 stripe ARI across 10 noise seeds; signed and spatially scrambled controls remain approximately zero. Other scenes regress strongly.

The exact interface

R[j] = state[depth[j]] - state[depth[j+1]]
original = core + sum(R[j])                  # identity
energy[j] = lattice_pool(norm(R[j]))         # unsigned
features = concat(core, beta * energy)       # hypothesis
graph = RBF_affinity(features)               # tested
segments = spectral_modes(graph)             # not learned

The proposed mechanism is not a discovery that “a sieve is an attention head.” Its more precise hypothesis is that spatially shared lifetimes can serve as a feature for a later relational graph. The surviving research problem is discriminating two-dimensional texture interiors from the narrow halos produced at ordinary object boundaries.
